# Web Chúc Mừng Sinh Nhật (Bản Không Giới Hạn Tuổi / Số Nến)

Ứng dụng web Chúc Mừng Sinh Nhật tương tác:
- **Không giới hạn tuổi & số nến:** Nhập bất kỳ số tuổi nào (18, 50, 100...), nến sẽ tự điều chỉnh để vừa chiếc bánh!
- **Tùy chỉnh thông tin:** Nhập tên người nhận, lời chúc, tên người gửi.
- **Upload Ảnh kỷ niệm:** Cho phép tải lên album ảnh cá nhân.
